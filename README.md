# K-Spot Trail (가칭)

K-pop 아티스트와 드라마·영화의 촬영지를 서울과 근교에서 찾아 안내하는, 외국인 팬을 위한 성지순례 앱입니다.
1차 버전은 BTS 중심이며, iOS와 Android를 지원합니다.

> 비공식 팬 가이드이며 해당 아티스트·작품·소속사와 관련이 없습니다.

## 현재 상태

기획 단계입니다. 아직 코드는 없습니다.
